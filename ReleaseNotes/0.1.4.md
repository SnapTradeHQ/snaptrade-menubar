# SnapTrade Menu Bar 0.1.4

- Signed with Passiv Inc.’s Apple Developer ID and notarized by Apple.
- Install normally from the DMG without a manual macOS security exception.
- Includes the portfolio features and update support from 0.1.3.

Upgrading from the beta: quit MenuBar, replace the app in Applications, and reopen it. If macOS asks to access your saved MenuBar tokens, choose Always Allow and enter your Mac login password to preserve your connection.

# SnapTrade Menu Bar 0.1.3

- Calculated totals now sum holdings and cash in each native currency across all accounts, including accounts with both CAD and USD assets.
- Broker-reported and calculated totals appear side by side. Currency groups with no nonzero totals are hidden.
- An info button explains how the totals are grouped. Removed the misleading difference between account reporting totals and native asset totals.
- First-time sync shows partial totals and positions as each account loads. Later refreshes keep the last complete portfolio visible.
- Interrupted first-time syncs retain partial results and offer a retry. Portfolio percentages and daily returns wait until loading finishes.

This beta uses Sparkle-signed updates and is not notarized by Apple.
